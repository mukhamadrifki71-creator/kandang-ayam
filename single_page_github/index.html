📋 Panduan 3 Menit Menghubungkan Supabase

Ikuti langkah mudah berikut agar data tersimpan aman di cloud Supabase dan terupdate secara real-time pada gawai/HP lain secara otomatis.

1

Buat Akun & Project Baru di Supabase

Buka https://supabase.com, buat project baru gratis.

2

Buka Menu "SQL Editor" & Jalankan Script di Bawah

Klik tombol "Salin SQL" di bawah, paste ke SQL Editor Supabase, lalu klik "Run". Script ini otomatis mengaktifkan tabel, izin publik, dan fitur real-time (publication).

3

Salin Project URL & Anon Key ke Web Ini

Masuk ke Project Settings → API. Salin URL dan anon public key, lalu klik tombol "Cek Koneksi" di kanan atas header untuk menyimpannya.
